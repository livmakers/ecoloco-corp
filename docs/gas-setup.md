# フォーム受信の設定手順（Google Apps Script／無料・約15分）

お問い合わせ・採用応募フォームの内容を、**Googleスプレッドシートに記録 → 担当者にGmail通知 → 送信者に自動返信**する仕組みです。月額費用はかかりません。

用意するもの：Googleアカウント（通知メールの「送信元」になります。会社用のGoogleアカウントがおすすめです）

---

## 手順1　スプレッドシートを作る
1. ブラウザで Google ドライブ（drive.google.com）を開く。
2. 左上「**＋ 新規**」→「**Google スプレッドシート**」→「空白のスプレッドシート」。
3. 左上のファイル名を「**ECOLOCO フォーム受信**」に変更する。
   > 📷 スクリーンショット位置：ファイル名を変更した直後の画面（左上のタイトル部分）

## 手順2　スクリプトを貼り付ける
1. スプレッドシートの上部メニュー「**拡張機能**」→「**Apps Script**」をクリック（新しいタブが開きます）。
2. 左側のファイル一覧に「コード.gs」（または Code.gs）があるので開く。中身を**すべて削除**する。
3. このフォルダの `gas/Code.gs` をメモ帳で開き、**全文をコピーして貼り付け**る。
4. 1行目あたりの `NOTIFY_EMAIL` が通知を受けたいメールアドレスになっているか確認する（初期値：ecoloco-yahoo@ysfree.jp）。
5. 上部の💾「**プロジェクトを保存**」をクリック。
   > 📷 スクリーンショット位置：貼り付け後、保存ボタンを押す直前の画面

## 手順3　ウェブアプリとして公開する
1. 右上の青いボタン「**デプロイ**」→「**新しいデプロイ**」。
2. 「種類の選択」の横の⚙（歯車）→「**ウェブアプリ**」を選ぶ。
3. 次のとおり設定する：
   - 説明：`ecoloco form`
   - 次のユーザーとして実行：**自分（あなたのメールアドレス）**
   - アクセスできるユーザー：**全員**
4. 「**デプロイ**」をクリック。
5. 「アクセスを承認」→ 使うGoogleアカウントを選ぶ →「詳細」→「（安全ではないページ）に移動」→「許可」。
   > ※「このアプリは確認されていません」と出ますが、自分で作ったスクリプトなので問題ありません。
   > 📷 スクリーンショット位置：承認画面（権限の一覧）
6. 表示される「**ウェブアプリ URL**（`https://script.google.com/macros/s/…/exec`）」を**コピー**する。
   > 📷 スクリーンショット位置：デプロイ完了画面（URLが表示される所）

## 手順4　サイトにURLを設定する
1. このフォルダの `config.js` をメモ帳で開く。
2. `GAS_ENDPOINT: "",` の `""` の中に、手順3でコピーしたURLを貼り付ける。
   ```js
   GAS_ENDPOINT: "https://script.google.com/macros/s/xxxxxxxx/exec",
   ```
3. 保存して、サイトのファイルを再アップロードする。

## 手順5　テスト送信
1. 公開したサイトの「お問い合わせ」ページから、自分のメールアドレスで送信する。
2. 次の3つを確認する：
   - ✅ スプレッドシートに「お問い合わせ」シートができて、1行追加されている
   - ✅ `NOTIFY_EMAIL` のアドレスに通知メールが届いた
   - ✅ 入力したメールアドレスに「受け付けました」の自動返信が届いた
3. 「RECRUIT」の応募フォームでも同様に確認する。

---

## 困ったときは
| 症状 | 確認すること |
|---|---|
| 「送信できませんでした」と出る | `config.js` のURLが `/exec` で終わっているか／デプロイの「アクセスできるユーザー」が「全員」か |
| スクリプトを直したのに反映されない | 「デプロイ」→「**デプロイを管理**」→ ✏ → バージョン「**新バージョン**」→「デプロイ」（URLは変わりません） |
| 通知メールが届かない | 迷惑メールフォルダ／`NOTIFY_EMAIL` の綴り |
| 返信元を変えたい | メールは、スクリプトを実行しているGoogleアカウントから送信されます。変更はそのアカウントの切り替えで行います |

## 注意
- 無料のGmail/Googleアカウントでは、1日に送れるメール数に上限があります（目安：約100通／日。通知＋自動返信で1件あたり2通）。通常の問い合わせ量なら問題ありません。
- 個人情報が入るスプレッドシートは、**共有範囲を必要な人だけ**にしてください。
- 通知先を変えるときは、`Code.gs` の `NOTIFY_EMAIL` と `config.js` の `NOTIFY_EMAIL` の**両方**を同じ値にして、手順の「デプロイを管理」から更新してください。
